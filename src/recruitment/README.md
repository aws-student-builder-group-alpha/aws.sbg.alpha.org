# Recruitment domain

Recruitment is part of the root Next.js application at `/recruitment`. Install dependencies and run all commands from the repository root. Configure the root `.env.local`; no separate recruitment package or server remains.

See the [root setup guide](../../README.md), [architecture](docs/architecture.md), and [progress tracker](docs/progress-tracker.md). Both areas share the main Supabase project and Google login; permissions stay independent. Recruitment starts fresh, and its old project is retained.
